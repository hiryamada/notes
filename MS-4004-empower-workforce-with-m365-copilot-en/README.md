# MS-4004 Empower your workforce with Microsoft 365 Copilot

https://learn.microsoft.com/en-us/training/paths/empower-workforce-copilot-use-cases/

Complete a series of hands-on exercises covering use cases for executives, sales, marketing, finance, IT, HR, operations, and more. These exercises focus on using Copilot in various Microsoft 365 apps (such as Word, PowerPoint, and Outlook) to complete common business tasks associated with each use case.
