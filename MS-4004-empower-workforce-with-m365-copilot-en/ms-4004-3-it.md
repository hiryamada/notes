
# Microsoft Copilot Demo for IT: Exercise 1

## Demo Overview

In this scenario, an IT professional launches a new IT project and uses Microsoft Copilot to explore the project, plan it, visualize it, and create presentation materials for stakeholders.

1. Create an IT project plan
2. Organize project risks and mitigations
3. Visualize the project in Whiteboard
4. Create stakeholder presentation materials in PowerPoint

> **Demo flow: Plan → Assess → Visualize → Communicate**

The total demo duration is 50 minutes.

# Exercise 1-1: Create an IT Project Plan

## App

[Open Microsoft 365 Copilot Chat](https://copilot.cloud.microsoft/home)

## Situation

You are starting a project to migrate an internal business system to the cloud.

Because a detailed plan has not yet been created, work with Copilot to organize the overall approach.

## Prompt

```text
We are planning a project to migrate an internal business system to the cloud.

Create an initial project plan.

Organize it around the following areas.

1. Project objectives
2. Major phases
3. Main tasks in each phase
4. Key stakeholders involved
5. Main deliverables for each phase
6. Items to confirm at the start of the project

Avoid focusing too heavily on technical details, and make the content understandable to both IT and business departments.
```

## Expected Outcome

Copilot creates an initial project plan covering phases such as:

- Current-state assessment
- Requirements definition
- Migration planning
- Design and implementation
- Testing
- User rollout
- Production cutover
- Start of operations

Demonstrate how a conversation with Copilot can help refine a project plan, rather than simply generate text.

## Follow-Up Prompt

To include an approximate timeline, add the following.

```text
Assuming this project will be completed in six months, add an approximate duration for each phase.
```

# Exercise 1-2: Organize Project Risks and Mitigations

## App

[Open Microsoft 365 Copilot Chat](https://copilot.cloud.microsoft/home)

## Situation

A high-level project plan is now available.

Next, work with Copilot to consider what problems might arise when executing the plan.

Continue the conversation from Exercise 1-1 without using existing project materials or past Teams chats.

## Prompt

```text
Organize the main risks anticipated in this cloud migration project and their mitigations.

Include at least the following areas.

- Schedule
- Technology
- Data migration
- Security
- User impact
- Stakeholder communication
- Post-migration operations

For each risk, organize the following in a table.

1. Description of the risk
2. Impact on the project
3. Preventive measures

Include risks related to people and business processes, not just technical issues.
```

## Expected Outcome

Risks such as the following are organized:

- Data migration delays
- Post-migration system issues
- Overlooked security requirements
- Insufficient user training
- Misalignment with business departments
- Schedule delays
- Inadequate post-migration operational support

Demonstrate how Copilot can serve as a **sounding board for project planning**, rather than just a text-generation tool.

## Follow-Up Prompt

```text
Select five risks from this list that should receive the highest priority at the start of the project.

Briefly explain why each is a high priority.
```

# Exercise 1-3: Visualize the Project Plan

## App

[Microsoft Whiteboard](https://whiteboard.cloud.microsoft/)

## Situation

The project plan and major risks have been organized.

Next, visually organize the main phases and tasks for use in a kickoff meeting with project members.

## Prompt

```text
Create a project plan for a kickoff meeting about migrating an internal business system to the cloud.

Organize the project into major phases such as:

- Current-state assessment
- Requirements definition
- Migration planning
- Design and implementation
- Testing
- User rollout
- Production cutover
- Start of operations

Add representative tasks for each phase.

Use a simple structure that is easy for participants from business departments, as well as IT, to understand.
```

## Expected Outcome

Project phases and tasks are organized visually.

Whiteboard lets participants do more than view a finished plan. During the meeting, they can add items such as:

- Missing tasks
- Responsible departments
- Points to note
- Ideas
- Risks
- Items to confirm

> In Whiteboard, focus on people discussing and improving the initial draft created by Copilot, rather than creating a finished plan from the outset.

# Exercise 1-4: Create Stakeholder Presentation Materials

## App

[Open PowerPoint](https://powerpoint.cloud.microsoft/)

## Situation

The project approach and major risks have been organized.

Next, create a presentation explaining the project to managers, business departments, and other stakeholders.

## Prompt

```text
Create a stakeholder presentation about a project to migrate an internal business system to the cloud.

Include the following.

1. Project background
2. Project objectives
3. Currently anticipated major phases
4. Key stakeholders involved
5. Main risks and mitigation approach
6. Expected benefits of the project
7. Next steps

Keep the content concise and avoid excessive jargon so participants outside IT can understand it.

Make the message on each slide clear, and prioritize understanding the overall project over detailed technical explanations.
```

## Expected Outcome

PowerPoint generates a presentation with a structure such as:

1. Project overview
2. Background and objectives
3. Project approach
4. Major phases
5. Stakeholders
6. Risks and mitigations
7. Expected benefits
8. Next steps

## Follow-Up Prompt

To make it more concise for executives:

```text
Assume a 10-minute executive briefing. Focus on the key messages and reduce the number of slides.
```

# Exercise 1 Summary

In this demo, an IT professional used Microsoft Copilot to launch a new project as follows.

| Stage | IT Activity | Tool |
|---|---|---|
| **Plan** | Create an initial project plan | [Microsoft 365 Copilot Chat](https://copilot.cloud.microsoft/home) |
| **Assess** | Consider risks and mitigations | [Microsoft 365 Copilot Chat](https://copilot.cloud.microsoft/home) |
| **Visualize** | Visualize the project plan | Microsoft Whiteboard |
| **Communicate** | Create stakeholder presentation materials | [PowerPoint](https://powerpoint.cloud.microsoft/) |

> The key point of this exercise is not to hand the project itself over to Copilot, but to support IT professionals' thinking and communication by drafting plans, identifying gaps and risks, visualizing information, and tailoring explanations to the audience.
