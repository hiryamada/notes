
# Microsoft Copilot IT向けデモ：演習1

## デモの概要

IT部門の担当者が、新しいITプロジェクトを立ち上げる場面を想定し、Microsoft Copilotを使用してプロジェクトの検討、計画、可視化、関係者への説明資料作成までを進めます。

1. ITプロジェクトの計画を作成する
2. プロジェクトのリスクと対応策を整理する
3. Whiteboardでプロジェクトを可視化する
4. PowerPointで関係者向け説明資料を作成する

> **デモの流れ：Plan → Assess → Visualize → Communicate**

デモの実施時間は合計50分です。

# 演習1-1：ITプロジェクトの計画を作成する

## 使用するアプリ

[Microsoft 365 Copilot Chatを開く](https://copilot.cloud.microsoft/home)

## シチュエーション

社内で利用している業務システムをクラウドへ移行するプロジェクトを開始することになりました。

まだ詳細な計画は作成されていないため、Copilotと相談しながらプロジェクト全体の進め方を整理します。

## プロンプト

```text
社内で利用している業務システムをクラウドへ移行するプロジェクトを計画しています。

プロジェクト計画のたたき台を作成してください。

以下の観点で整理してください。

1. プロジェクトの目的
2. 主要なフェーズ
3. 各フェーズで実施する主なタスク
4. 関係する主なステークホルダー
5. 各フェーズの主な成果物
6. プロジェクト開始時に確認すべき事項

技術的な詳細に偏りすぎず、IT部門と業務部門の両方が理解できる内容にしてください。
```

## 想定する結果

Copilotによって、例えば次のようなプロジェクト計画のたたき台が作成されます。

- 現状調査
- 要件整理
- 移行計画
- 設計・構築
- テスト
- ユーザーへの展開
- 本番移行
- 運用開始

単純に文章を生成するのではなく、Copilotと会話しながらプロジェクト計画を具体化できることを確認します。

## 追加プロンプト

期間のイメージも含めたい場合は、次のように追加します。

```text
このプロジェクトを6か月で実施すると仮定して、各フェーズの大まかな期間も追加してください。
```

# 演習1-2：プロジェクトのリスクと対応策を整理する

## 使用するアプリ

[Microsoft 365 Copilot Chatを開く](https://copilot.cloud.microsoft/home)

## シチュエーション

プロジェクトの大まかな計画ができました。

次に、計画を実行する際にどのような問題が発生する可能性があるかをCopilotと一緒に検討します。

既存のプロジェクト資料や過去のTeamsチャットなどは使用せず、演習1-1から続けてCopilotと相談します。

## プロンプト

```text
このクラウド移行プロジェクトを進める際に想定される主なリスクと、その対応策を整理してください。

少なくとも以下の観点を含めてください。

- スケジュール
- 技術
- データ移行
- セキュリティ
- ユーザーへの影響
- 関係者とのコミュニケーション
- 移行後の運用

各リスクについて、

1. リスクの内容
2. プロジェクトへの影響
3. 事前にできる対策

を表形式で整理してください。

技術的な問題だけではなく、人や業務に関するリスクも含めてください。
```

## 想定する結果

例えば次のようなリスクが整理されます。

- データ移行の遅延
- 移行後のシステムトラブル
- セキュリティ要件の漏れ
- ユーザー教育不足
- 業務部門との認識のずれ
- スケジュール遅延
- 移行後の運用体制不足

Copilotを単なる文章生成ツールとしてではなく、**プロジェクトを検討する際の壁打ち相手**として利用できることを確認します。

## 追加プロンプト

```text
この中から、プロジェクト開始時に特に優先して確認すべきリスクを5つ選んでください。

それぞれ、なぜ優先度が高いのかも簡潔に説明してください。
```

# 演習1-3：プロジェクト計画を可視化する

## 使用するアプリ

[Microsoft Whiteboard](https://whiteboard.cloud.microsoft/)

## シチュエーション

プロジェクトの計画と主なリスクが整理できました。

次に、プロジェクトメンバーとのキックオフミーティングで使用できるように、主要なフェーズやタスクを視覚的に整理します。

## プロンプト

```text
社内業務システムをクラウドへ移行するプロジェクトについて、キックオフミーティングで使用するプロジェクト計画を作成してください。

プロジェクトを次のような主要フェーズに分けて整理してください。

- 現状調査
- 要件整理
- 移行計画
- 設計・構築
- テスト
- ユーザーへの展開
- 本番移行
- 運用開始

各フェーズについて、代表的なタスクも追加してください。

IT部門だけでなく業務部門の参加者にも理解しやすい、シンプルな構成にしてください。
```

## 想定する結果

プロジェクトの各フェーズやタスクが視覚的に整理されます。

Whiteboardを使用することで、完成した計画を見るだけではなく、ミーティング中に次のような内容を参加者と追加できます。

- 抜けているタスク
- 担当部門
- 注意点
- アイデア
- リスク
- 確認事項

> Whiteboardでは、最初から完成した計画を作ることよりも、Copilotが作成したたたき台を人間が議論しながら改善していく使い方に注目します。

# 演習1-4：関係者向け説明資料を作成する

## 使用するアプリ

[PowerPointを開く](https://powerpoint.cloud.microsoft/)

## シチュエーション

プロジェクトの進め方と主なリスクが整理できました。

次に、マネージャーや業務部門などの関係者へプロジェクトを説明するためのプレゼンテーションを作成します。

## プロンプト

```text
社内業務システムをクラウドへ移行するプロジェクトについて、関係者向けの説明資料を作成してください。

次の内容を含めてください。

1. プロジェクトの背景
2. プロジェクトの目的
3. 現在想定している主要なフェーズ
4. 関係する主なステークホルダー
5. 主なリスクと対応方針
6. プロジェクトによって期待される効果
7. 次のステップ

IT部門以外の参加者にも理解できるように、専門用語を使いすぎず、簡潔な内容にしてください。

各スライドではメッセージを明確にし、詳細な技術説明よりもプロジェクト全体の理解を優先してください。
```

## 想定する結果

PowerPointに、例えば次のような構成のプレゼンテーションが生成されます。

1. プロジェクト概要
2. 背景と目的
3. プロジェクトの進め方
4. 主要フェーズ
5. 関係者
6. リスクと対応
7. 期待される効果
8. 次のステップ

## 追加プロンプト

経営層向けにさらに簡潔にする場合：

```text
経営層への10分間の説明を想定して、重要なメッセージに絞り、スライド数を減らしてください。
```

# 演習1のまとめ

このデモでは、IT担当者が新しいプロジェクトを立ち上げる場面を想定し、Microsoft Copilotを次のように利用しました。

| 段階 | IT業務 | 使用するツール |
|---|---|---|
| **Plan** | プロジェクト計画のたたき台を作る | [Microsoft 365 Copilot Chat](https://copilot.cloud.microsoft/home) |
| **Assess** | リスクと対応策を検討する | [Microsoft 365 Copilot Chat](https://copilot.cloud.microsoft/home) |
| **Visualize** | プロジェクトの計画を視覚化する | Microsoft Whiteboard |
| **Communicate** | 関係者向けの説明資料を作成する | [PowerPoint](https://powerpoint.cloud.microsoft/) |

> Copilotにプロジェクトそのものを任せるのではなく、計画のたたき台を作る、抜けやリスクを検討する、情報を可視化する、相手に合わせて説明する、といったIT担当者の思考とコミュニケーションをCopilotで支援することが、この演習のポイントです。
