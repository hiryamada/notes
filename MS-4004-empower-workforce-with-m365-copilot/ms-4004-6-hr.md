
# Microsoft Copilot HR向けデモ：演習1

## デモの概要

人事担当者が、社内研修の受講状況を確認し、対象者への案内やフォローアップを行う場面を想定します。

Microsoft Copilotを使用して、受講データの確認、傾向の分析、フォローアップ方針の整理、対象者への案内メール作成までを進めます。

1. 研修受講データを確認する
2. 受講状況を分析する
3. フォローアップの方針を整理する
4. 対象者への案内メールを作成する

> **デモの流れ：Review → Analyze → Plan → Communicate**

デモの実施時間は合計50分です。

# 演習1-1：研修受講データを確認する

## 使用するアプリ

[Excelを開く](https://excel.cloud.microsoft/)

## シチュエーション

全社向けの必須研修を実施しています。

受講期限が近づいてきたため、人事担当者として現在の受講状況を確認し、フォローアップが必要な対象者を把握します。

実際の従業員データではなく、架空の従業員データを使用します。

## サンプルデータ

次のような列を持つExcelファイルを用意します。

- Employee ID
- Department
- Course
- Assigned Date
- Due Date
- Completion Date
- Status

個人名は必須ではありません。

Employee IDも以下のような架空の値でかまいません。

- E001
- E002
- E003
- E004

## プロンプト

```text
この研修受講データを確認してください。

以下の観点で整理してください。

1. 対象者の総数
2. 受講済みの人数
3. 未受講の人数
4. 受講率
5. 受講期限が近い未受講者
6. すでに受講期限を過ぎている対象者
7. フォローアップが必要な対象

必要であれば、受講状況を分かりやすく確認できる列を追加してください。

元データにない従業員情報や受講理由は推測しないでください。
```

## 想定する結果

Excel上で、例えば次の内容が整理されます。

- 対象人数
- Completed
- Not Completed
- Completion Rate
- Due Soon
- Overdue
- Follow-up Required

> HRデモでは、Copilotに従業員を「評価」させるのではなく、データ上の受講状況を整理することに注目します。

## 追加プロンプト

```text
フォローアップが必要な対象を分かりやすく確認できるようにしてください。

次の3つに分類してください。

- 受講済み
- 期限間近
- 期限超過
```

# 演習1-2：受講状況を分析する

## 使用するアプリ

[Excelを開く](https://excel.cloud.microsoft/)

## シチュエーション

個々の受講状況を確認できました。

次に、部門ごとの受講状況を集計して、フォローアップが必要な範囲を確認します。

同じExcelファイルをそのまま使用します。

## プロンプト

```text
この研修受講データについて、部門別の受講状況を分析してください。

部門ごとに以下を整理してください。

1. 対象人数
2. 受講済み人数
3. 未受講人数
4. 受講率
5. 期限間近の件数
6. 期限超過の件数

部門間で違いがある場合は、データから確認できる事実として説明してください。

受講率の違いについて、データから確認できない原因を推測しないでください。
```

## 想定する結果

部門別に、次のような情報が比較できるようになります。

- 対象者数
- 受講済み人数
- 未受講人数
- 受講率
- 期限間近
- 期限超過

## 追加プロンプト：グラフを作成する

```text
部門ごとの受講状況を比較できるグラフを作成してください。

各部門の受講率の違いが分かりやすいグラフにしてください。
```

## 追加プロンプト：フォローアップ対象を整理する

```text
フォローアップを検討すべき対象を、

1. 期限超過
2. 期限間近
3. その他の未受講

の順番で整理してください。
```

> この優先順位は業務管理上の期限に基づくものであり、従業員個人の能力や勤務態度を評価するものではありません。

# 演習1-3：フォローアップ方針を整理する

## 使用するアプリ

[Microsoft 365 Copilot Chatを開く](https://copilot.cloud.microsoft/home)

## シチュエーション

研修の受講状況を分析した結果、期限間近または期限超過の対象者がいることが分かりました。

次に、対象者へどのようにフォローアップするかを検討します。

## プロンプト

```text
社内の必須研修について、未受講者へのフォローアップ方法を検討しています。

次の3つの対象について、それぞれ適切なフォローアップ方法を整理してください。

1. 受講期限に余裕がある未受講者
2. 受講期限が近い未受講者
3. 受講期限を過ぎた未受講者

それぞれについて、

- 伝えるべき内容
- コミュニケーションのトーン
- 推奨するタイミング
- 必要なアクション
- マネージャーへの連絡を検討する条件

を整理してください。

未受講の理由を推測したり、従業員の姿勢や能力を評価したりせず、研修の受講状況と期限という事実に基づいてください。
```

## 想定する結果

受講状況に応じて、フォローアップ方法が整理されます。

例えば以下です。

### 期限まで余裕がある

- 通常の案内
- 研修の目的
- 受講期限
- 受講方法

### 期限間近

- リマインダー
- 明確な期限
- 必要なアクション

### 期限超過

- 未完了であることの通知
- 早期の対応依頼
- 必要に応じたマネージャーとの確認

重要なのは、**「なぜ受講していないのか」をCopilotに推測させない**ことです。

# 演習1-4：対象者への案内メールを作成する

## 使用するアプリ

[Outlookメールを開く](https://outlook.cloud.microsoft/mail/)

## シチュエーション

受講期限が近い対象者へのフォローアップ方針が決まりました。

次に、従業員へ送るリマインダーメールを作成します。

既存のOutlookメールは使用せず、新規メールとして作成します。

## プロンプト

```text
社内の必須研修について、受講期限が近い従業員に送るリマインダーメールを作成してください。

以下の内容を含めてください。

1. 必須研修についてのリマインダーであること
2. 受講期限
3. 期限までに受講を完了してほしいこと
4. 受講方法を確認してほしいこと
5. 問題がある場合は担当窓口へ連絡してほしいこと

簡潔で丁寧な文章にしてください。

未受講の理由を推測したり、従業員の勤務態度や能力について評価する表現は含めないでください。

責めるような表現は避け、必要なアクションが明確に分かる内容にしてください。
```

## 想定する結果

Outlookに、対象者へ送付する前にレビューできるメールの下書きが作成されます。

メールには次の情報が含まれます。

- Purpose
- Training
- Due Date
- Required Action
- Support

## 追加プロンプト：短くする

```text
必要な内容を維持したまま、メールをもう少し短くしてください。

受講期限と必要なアクションが一目で分かるようにしてください。
```

## 追加プロンプト：期限超過版に変更する

```text
このメールを、すでに受講期限を過ぎている対象者向けに変更してください。

責めるような表現は避け、現在未完了であることと、必要な対応を明確にしてください。
```

# 演習1のまとめ

このデモでは、人事担当者が研修受講状況を確認してから、対象者へフォローアップするまでを体験しました。

| 段階 | HR業務 | 使用するツール |
|---|---|---|
| **Review** | 研修受講状況を確認する | [Excel](https://excel.cloud.microsoft/) |
| **Analyze** | 部門別の受講状況を分析する | [Excel](https://excel.cloud.microsoft/) |
| **Plan** | フォローアップ方法を整理する | [Microsoft 365 Copilot Chat](https://copilot.cloud.microsoft/home) |
| **Communicate** | 対象者へのリマインダーを作成する | [Outlookメール](https://outlook.cloud.microsoft/mail/) |

> Copilotに従業員を評価させるのではなく、受講状況などの客観的な情報を整理し、人事担当者が適切なフォローアップを行うために活用することが、この演習のポイントです。

# デモ実施上のポイント

この演習では、実際の従業員情報や既存の社内コミュニケーションを使用しません。

- 実際の従業員情報：使用しない
- 実際の研修履歴：使用しない
- 既存Outlookメール：使用しない
- 既存Teamsチャット：使用しない
- 実際の人事評価データ：使用しない
- HR Agent：使用しない
- Loop：使用しない

演習用に架空の研修受講データを含むExcelファイルを1つ準備するだけで実施できる構成です。

## サンプルExcelを準備する際のポイント

15～20人程度の架空データで十分です。

意図的に次のパターンを混ぜます。

- 受講済み
- 未受講だが期限まで余裕がある
- 期限まで数日
- 期限超過
- 部門によって受講率に違いがある

ただし、未受講の「理由」はデータに含めないことを推奨します。

これにより、

**確認できる事実：**
「営業部門は20名中15名が受講済み」

と、

**根拠のない推測：**
「営業部門は忙しいから受講できていない」

の違いもデモで説明できます。
