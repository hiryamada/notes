# Microsoft Copilot 営業向けデモ：演習1

## デモの概要

営業担当者が、新規顧客への提案に向けて、次の一連の業務をMicrosoft Copilotで進めるシナリオです。

1. 市場や競合を調査する
2. 営業提案の方向性を相談する
3. 顧客向け提案書を作成する
4. 顧客へのメールを作成する

> **デモの流れ：Research → Think → Create → Communicate**

デモの実施時間は合計50分です。

## 演習1-1のプロンプト

### 使用するツール

[リサーチツールを開く](https://copilot.cloud.microsoft/agents/researcher)

### シチュエーション

新しい医療機関への提案に向けて、日本の医療DX市場、医療機関が抱えている課題、主要企業の動向を調査します。

### プロンプト

```text
日本国内の医療DX市場について調査してください。

特に、以下の観点で整理してください。

1. 電子カルテ、医療情報システム、クリニックの業務効率化に関する主要な市場動向
2. 医療機関が抱えている主要な課題
3. 医療DXに関連する主要企業と、それぞれの公開情報上の特徴
4. 今後、医療機関で需要が高まると考えられるソリューション
5. 営業担当者が顧客への提案を検討する際に注目すべきポイント

公開されている情報に基づいて回答し、使用した情報の出典を示してください。
事実と推測を区別し、確認できない内容は断定しないでください。
```

### 想定する結果

リサーチツールによって、次のような内容を含む調査レポートが生成されます。

- 日本における医療DXの市場動向
- 医療機関が抱える代表的な課題
- 主要企業とソリューションの特徴
- 今後の市場機会
- 営業提案で検討すべきポイント
- 参照した情報源

### デモ実施上のポイント

リサーチツールはレポートの生成に時間がかかる場合があります。

デモでは、次の流れを事前に録画しておき、待ち時間をカットした動画を使用する方法があります。

1. プロンプトを入力する
2. 調査を開始する
3. 処理中の画面を数秒見せる
4. 待ち時間をカットする
5. 完成したレポートを表示する
6. レポートの構成と出典を確認する

## 演習1-2のプロンプト

### 使用するアプリ

[Microsoft 365 Copilot Chatを開く](https://copilot.cloud.microsoft/home)

### シチュエーション

市場について調査した後、営業担当者として何を顧客に提案すべきか、Copilotに相談します。

このデモでは、過去のメール、Teamsチャット、顧客ファイルなどは使用せず、一般的な営業シナリオについて新しいチャットを開始します。

### プロンプト

```text
医療機関に医療DXソリューションを提案する営業担当者として、初回提案で重視すべきポイントを整理してください。

以下の3つに分けて回答してください。

1. 医療機関が抱えていると想定される代表的な課題
2. 提案時の主な訴求ポイント
3. 顧客の状況を理解するために確認すべき質問

顧客ごとに状況が異なるため、顧客固有の課題を断定しないでください。
初回の顧客ヒアリングと提案準備に使用できる、実践的で簡潔な内容にしてください。
```

### 想定する結果

Copilotとの新しいチャットによって、次の内容が整理されます。

- 想定される顧客課題
- 営業提案で使用できる訴求ポイント
- 初回ヒアリングで確認すべき質問
- 顧客の状況に応じて調整すべき項目

### 追加プロンプト

回答が長い場合は、次のプロンプトで簡潔にできます。

```text
この内容を、営業担当者が初回訪問前に確認できる1ページ分のチェックリストに整理してください。
```

## 演習1-3のプロンプト

### 使用するアプリ

[Wordを開く](https://word.cloud.microsoft/)

### シチュエーション

医療機関への提案の方向性を基に、初回ディスカッションで使用する提案書のドラフトを新規作成します。

既存の顧客ファイルは使用せず、空白のWord文書から開始します。

### プロンプト

```text
医療機関向けの医療DX提案書のドラフトを作成してください。

以下の構成にしてください。

1. 背景
2. 医療機関が抱えている代表的な課題
3. 解決の方向性
4. 期待される効果
5. 導入を検討する際の確認事項
6. 次のステップ

初回の顧客ディスカッションで使用することを想定し、簡潔で分かりやすく、専門的な文体にしてください。

顧客固有の状況は断定せず、個別に確認する必要がある内容については「要確認」と記載してください。
具体的な製品名やサービス名を過度に使用せず、顧客の課題と期待される成果を中心に記述してください。
```

### 想定する結果

Wordに、次の内容を含む提案書の初稿が生成されます。

- 医療DXが必要とされる背景
- 医療機関が抱えている代表的な課題
- 解決に向けた方向性
- 期待される業務上の効果
- 顧客への確認事項
- 次回の打ち合わせに向けたステップ

### 追加プロンプト：文章を短くする

```text
エグゼクティブサマリーとして使用できるように、冒頭部分を半分程度の長さに短縮してください。
```

### 追加プロンプト：経営層向けに調整する

```text
医療機関の経営層が短時間で理解できるように、技術的な表現を減らし、業務上の効果を中心とした内容に書き換えてください。
```

## 演習1-4のプロンプト

### 使用するアプリ

[Outlookメールを開く](https://outlook.cloud.microsoft/mail/)

### シチュエーション

提案書の準備ができたため、見込み顧客に新規メールを作成し、提案内容を紹介するための30分の打ち合わせを依頼します。

既存のメールスレッドは使用せず、新規メールの作成から開始します。

### プロンプト

```text
医療機関のお客様に、医療DXについての提案をご紹介するため、30分の打ち合わせをお願いするメールを作成してください。

メールには、以下の内容を含めてください。

1. ご連絡した目的
2. ご紹介したい提案のポイント
3. 30分の打ち合わせのお願い
4. 都合のよい日時を確認する文章

提案のポイントは3点以内で簡潔に示してください。
売り込みが強すぎない、丁寧で自然な日本語にしてください。
顧客の現在の課題を確認できていないため、顧客固有の状況を断定しないでください。
```

### 想定する結果

Outlookに、次の内容を含む新規メールの下書きが作成されます。

- 連絡の目的
- 医療DX提案の概要
- 顧客に期待される価値
- 30分の打ち合わせ依頼
- 候補日時を確認する文章

### 追加プロンプト：短くする

```text
初回のご連絡として読みやすいように、メール全体をもう少し短くしてください。
```

### 追加プロンプト：トーンを調整する

```text
売り込みの印象を弱め、情報交換をご提案する柔らかい表現に変更してください。
```

## 演習1のまとめ

このデモでは、営業担当者の業務を次の4段階で体験します。

| 段階 | 営業活動 | 使用するツール |
|---|---|---|
| **Research** | 市場、顧客課題、主要企業について調査する | [リサーチツール](https://copilot.cloud.microsoft/agents/researcher) |
| **Think** | 顧客への提案内容とヒアリング項目を整理する | [Microsoft 365 Copilot Chat](https://copilot.cloud.microsoft/home) |
| **Create** | 顧客向け提案書のドラフトを作成する | [Word](https://word.cloud.microsoft/) |
| **Communicate** | 顧客へのアポイント依頼メールを作成する | [Outlookメール](https://outlook.cloud.microsoft/mail/) |

> Copilotの個々の機能を別々に使用するのではなく、調査、検討、成果物の作成、顧客とのコミュニケーションを一つの業務フローとしてつなげることが、この演習のポイントです。
