
# Microsoft Copilot Communications向けデモ：演習1

## デモの概要

社内コミュニケーション担当者が、新しい社内施策を従業員へ周知する場面を想定します。

Microsoft Copilotを使用して、テーマに関する情報収集、アナウンス文書の作成、対象者データの整理、説明資料の作成までを進めます。

1. 社内施策に関する情報を調査する
2. 社内アナウンスを作成する
3. 対象者データを整理する
4. 説明会用プレゼンテーションを作成する

> **デモの流れ：Research → Write → Organize → Present**

デモの実施時間は合計50分です。

# 演習1-1：施策に関する情報を調査する

## 使用するツール

[リサーチツールを開く](https://copilot.cloud.microsoft/agents/researcher)

## シチュエーション

社内で新しいハイブリッドワーク施策を導入することになりました。

従業員向けのコミュニケーションを計画する前に、ハイブリッドワークに関する最近の動向や、従業員への説明で注意すべきポイントを調査します。

## プロンプト

```text
ハイブリッドワークに関する最近の動向について調査してください。

特に以下の観点で整理してください。

1. ハイブリッドワークに関する最近の主要なトレンド
2. 従業員側で発生しやすい課題
3. 組織側で発生しやすい課題
4. 新しい働き方を導入する際に従業員へ明確に伝えるべき内容
5. 社内コミュニケーションを行う際の注意点
6. 従業員から想定される代表的な質問

公開されている情報に基づいて回答し、使用した情報の出典を示してください。

企業ごとに制度や状況が異なるため、一般的な傾向と個別企業のルールを区別してください。
```

## 想定する結果

リサーチツールによって、例えば以下の内容を含むレポートが作成されます。

- ハイブリッドワークの動向
- 従業員側の課題
- 組織側の課題
- コミュニケーションで伝えるべきポイント
- 想定される質問
- 情報源

## デモ実施上のポイント

リサーチツールは回答生成に時間がかかる場合があります。

デモでは成功した実行結果を事前に録画しておき、待ち時間をカットした動画をバックアップとして準備しておくことができます。

# 演習1-2：社内アナウンスを作成する

## 使用するアプリ

[Wordを開く](https://word.cloud.microsoft/)

## シチュエーション

調査によって、従業員へのコミュニケーションで注意すべきポイントが整理できました。

次に、新しいハイブリッドワーク施策を従業員へ案内する文書を作成します。

既存の社内文書は使用せず、新しいWord文書から開始します。

## プロンプト

```text
従業員向けに、新しいハイブリッドワーク施策について案内する社内アナウンスを作成してください。

以下の構成にしてください。

1. この案内の目的
2. 新しい働き方を導入する背景
3. 何が変わるのか
4. 従業員への主な影響
5. 従業員にお願いするアクション
6. 制度開始までのスケジュール
7. よくある質問
8. 問い合わせ先

具体的な会社固有の制度や日付については、確認できていないため断定しないでください。
必要な箇所は「要確認」としてください。

従業員が短時間で内容を理解できる、明確で親しみやすい文章にしてください。
```

## 想定する結果

Wordに、例えば次の内容を含む社内アナウンスのドラフトが作成されます。

- Purpose
- Background
- What is changing
- Employee impact
- Required actions
- Timeline
- FAQ
- Contact information

## 追加プロンプト：短くする

```text
従業員が2分程度で読めるように、重要な内容を維持したまま文章を短くしてください。
```

## 追加プロンプト：冒頭を改善する

```text
文書の冒頭に、

「何が変わるのか」
「いつから変わるのか」
「自分は何をすればよいのか」

が一目で分かる要約を追加してください。
```

# 演習1-3：コミュニケーション対象を整理する

## 使用するアプリ

[Excelを開く](https://excel.cloud.microsoft/)

## シチュエーション

全従業員向けの基本的なアナウンスができました。

一方で、勤務形態や拠点などによって、必要な案内が異なる可能性があります。

デモ用の架空の対象者データを使用して、コミュニケーション対象を整理します。

## サンプルデータ

例えば、次の列を持つExcelファイルを用意します。

- Employee ID
- Location
- Work Style
- Department
- Communication Status

実際の従業員名やメールアドレスは必要ありません。

## プロンプト

```text
この従業員向けコミュニケーション対象データを整理してください。

新しいハイブリッドワーク施策について案内することを想定しています。

以下の観点で整理してください。

1. 拠点別の対象人数
2. 勤務形態別の対象人数
3. 部門別の対象人数
4. まだ案内されていない対象
5. 対象グループによって追加説明が必要になる可能性がある項目

対象者ごとの能力、勤務態度、考え方などは推測しないでください。

あくまでデータ上の属性とコミュニケーション状況を整理してください。
```

## 想定する結果

例えば次の内容が整理されます。

- 拠点別の対象人数
- 勤務形態別の対象人数
- 部門別の対象人数
- Communication Completed
- Communication Pending
- 対象ごとに確認すべき情報

## 追加プロンプト

```text
コミュニケーション状況を確認しやすいように、

- 案内済み
- 未案内

を分かりやすく整理してください。
```

## 追加プロンプト：グループ別に整理する

```text
勤務形態ごとに、

1. 全員に共通して伝える情報
2. そのグループに追加で伝える必要がある可能性のある情報

を整理してください。

元データだけでは判断できない内容は「要確認」としてください。
```

# 演習1-4：説明会用資料を作成する

## 使用するアプリ

[PowerPointを開く](https://powerpoint.cloud.microsoft/)

## シチュエーション

従業員へのアナウンス内容と、コミュニケーション対象が整理できました。

次に、新しい働き方について従業員へ説明するためのプレゼンテーションを作成します。

## プロンプト

```text
従業員向けに、新しいハイブリッドワーク施策について説明するプレゼンテーションを作成してください。

以下の内容を含めてください。

1. なぜ変更するのか
2. 何が変わるのか
3. 何が変わらないのか
4. 従業員への影響
5. 従業員にお願いするアクション
6. 導入までのスケジュール
7. よくある質問
8. 問い合わせ先

15分程度の説明会で使用できる、簡潔で分かりやすい構成にしてください。

具体的な会社固有のルールや日付が確認できていない部分は、「要確認」としてください。

詳細な制度説明だけではなく、従業員が

「何が変わるのか」
「自分にどのような影響があるのか」
「何をすればよいのか」

を理解できる内容を優先してください。
```

## 想定する結果

PowerPointに、例えば次のような構成のプレゼンテーションが作成されます。

1. 新しい働き方について
2. 変更の背景
3. 変更内容
4. 変わらないこと
5. 従業員への影響
6. 必要なアクション
7. スケジュール
8. FAQ
9. 問い合わせ先

## 追加プロンプト：重要メッセージを強調する

```text
冒頭のスライドで、

「何が変わるのか」
「いつから変わるのか」
「従業員は何をすればよいのか」

の3点がすぐに理解できる構成にしてください。
```

# 演習1のまとめ

このデモでは、社内コミュニケーション担当者が情報を集めてから、従業員へ分かりやすく届けるまでを体験しました。

| 段階 | コミュニケーション業務 | 使用するツール |
|---|---|---|
| **Research** | テーマに関する情報を調査する | [リサーチツール](https://copilot.cloud.microsoft/agents/researcher) |
| **Write** | 社内アナウンスを作成する | [Word](https://word.cloud.microsoft/) |
| **Organize** | コミュニケーション対象を整理する | [Excel](https://excel.cloud.microsoft/) |
| **Present** | 従業員向け説明資料を作成する | [PowerPoint](https://powerpoint.cloud.microsoft/) |

> Copilotに社内方針そのものを決めてもらうのではなく、必要な情報を集め、対象者と伝えるべき内容を整理し、相手が理解しやすいコミュニケーションへ変換することが、この演習のポイントです。

# デモ実施上のポイント

この演習では、実際の社内コミュニケーションデータへ依存しない構成にしています。

- 実際の従業員データ：使用しない
- 既存メール：使用しない
- 既存Teamsチャット：使用しない
- 既存社内文書：使用しない
- Viva Engage：使用しない
- Idea Coach：使用しない
- Agent Builder：使用しない

演習1-3だけ、15～20件程度の架空データを含むサンプルExcelファイルを使用します。

そのため、主な事前準備は次の2つです。

1. コミュニケーション対象者のサンプルExcel
2. リサーチツールのバックアップ用実行結果

## サンプルExcelを準備する際のポイント

個人名やメールアドレスは不要です。

例えば次のようなデータだけで十分です。

| Employee ID | Location | Work Style | Department | Communication Status |
|---|---|---|---|---|
| E001 | Tokyo | Hybrid | Sales | Completed |
| E002 | Osaka | Office | Finance | Pending |
| E003 | Tokyo | Remote | Marketing | Pending |
| E004 | Nagoya | Hybrid | IT | Completed |

これにより、実際の従業員情報を扱わずに、

**「誰に何を伝える必要があるかを整理する」**

というCommunications業務をデモできます。
