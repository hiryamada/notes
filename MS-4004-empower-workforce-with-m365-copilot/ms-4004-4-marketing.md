
# Microsoft Copilot Marketing向けデモ：演習1

## デモの概要

マーケティング担当者が、新しいデジタルサービスのマーケティング施策を検討する場面を想定します。

Microsoft Copilotを使用して、市場や顧客ニーズを調査し、マーケティングデータを分析し、ターゲット顧客や施策の方向性を整理します。

1. 市場と顧客ニーズを調査する
2. マーケティングデータを分析する
3. 調査と分析からマーケティング施策を検討する
4. キャンペーン案を作成する

> **デモの流れ：Research → Analyze → Strategize → Create**

デモの実施時間は合計50分です。

# 演習1-1：市場と顧客ニーズを調査する

## 使用するツール

[リサーチツールを開く](https://copilot.cloud.microsoft/agents/researcher)

## シチュエーション

新しい法人向けデジタルサービスのマーケティング施策を検討することになりました。

まず、市場でどのような変化が起きているのか、顧客企業がどのような課題を抱えているのかを調査します。

## プロンプト

```text
日本国内の法人向けデジタルサービス市場について調査してください。

特に以下の観点で整理してください。

1. 最近の主要な市場動向
2. 顧客企業が抱えている代表的な課題
3. 購買を検討する際に重視されるポイント
4. 主要な企業やサービスと公開情報上の特徴
5. 今後需要が高まる可能性のある領域
6. マーケティング担当者が注目すべき機会

公開されている情報に基づいて回答し、使用した情報の出典を示してください。

事実と推測を区別し、確認できない内容は断定しないでください。
```

## 想定する結果

例えば以下のような市場調査レポートが生成されます。

- 市場の主要トレンド
- 法人顧客が抱える課題
- 購買時に重視されるポイント
- 主要企業・サービス
- 市場機会
- マーケティング上の示唆
- 情報源

## デモ実施上のポイント

リサーチツールでは生成に時間がかかる場合があります。

そのため、デモでは成功した実行例を事前に録画しておき、待ち時間をカットした動画をバックアップとして準備しておくことができます。

# 演習1-2：マーケティングデータを分析する

## 使用するツール

[アナリストを開く](https://copilot.cloud.microsoft/agents/analyst)

## シチュエーション

外部市場について理解できました。

次に、過去のマーケティング施策のデータから、どのチャネルや施策の成果が高かったのかを分析します。

この演習では、実際の企業データではなく、デモ用のサンプルデータを使用します。

## サンプルデータの例

以下のような項目を含むシンプルなExcelファイルを使用します。

- Campaign
- Channel
- Impressions
- Clicks
- Leads
- Cost
- Conversions

## プロンプト

```text
このマーケティングキャンペーンデータを分析してください。

特に以下を確認してください。

1. チャネルごとの成果
2. コンバージョンが多いキャンペーン
3. コストに対して成果の高い施策
4. 成果が低い、または改善が必要と考えられる施策
5. データから読み取れる主な傾向
6. 次回のキャンペーンを計画する際に検討すべきポイント

重要な指標は比較しやすい形で整理してください。

データから確認できない原因については断定せず、仮説として示してください。
```

## 想定する結果

アナリストによって、例えば以下のような分析が行われます。

- チャネル別の成果比較
- コンバージョン率
- コスト効率
- 成果の高いキャンペーン
- 成果の低いキャンペーン
- データ上の傾向
- 次回施策を検討するときのポイント

> このデモでは「数字を計算する」だけではなく、複数の指標からマーケティング担当者が注目すべき傾向を見つけることを重視します。

## 追加プロンプト

```text
この分析結果から、マーケティング担当者が特に注目すべきポイントを3つに絞ってください。

それぞれについて、

- データから確認できる事実
- 考えられる仮説
- 次に確認すべきこと

を分けて説明してください。
```

# 演習1-3：マーケティング戦略を検討する

## 使用するアプリ

[Microsoft 365 Copilot Chatを開く](https://copilot.cloud.microsoft/home)

## シチュエーション

市場調査とマーケティングデータの分析ができました。

次に、新しい法人向けデジタルサービスについて、誰に何を訴求し、どのようなチャネルで届けるかを検討します。

## プロンプト

```text
新しい法人向けデジタルサービスのマーケティング施策を検討しています。

これまでの市場調査とマーケティングデータ分析を踏まえるという想定で、マーケティング施策のたたき台を作成してください。

以下の項目で整理してください。

1. 主なターゲット顧客
2. ターゲット顧客が抱えていると想定される課題
3. 提供すべき主要なメッセージ
4. 利用するマーケティングチャネル
5. 作成すべきコンテンツ
6. 顧客に期待する次のアクション
7. 効果測定に使用するKPI

顧客のニーズを断定せず、実際のデータや顧客調査で確認する必要がある内容については、その旨を示してください。
```

## 想定する結果

マーケティング施策の基本要素が整理されます。

例えば以下です。

- Target
- Customer Need
- Message
- Channel
- Content
- Call to Action
- KPI

ここではCopilotに戦略判断を任せるのではなく、**市場調査とデータ分析から得た情報を、実行可能な施策へ整理する**ことを重視します。

## 追加プロンプト

```text
この施策について、

「誰に」
「何を伝え」
「どのチャネルで届け」
「どの行動につなげるか」

の4点が分かるように、1ページで整理してください。
```

# 演習1-4：キャンペーン案を作成する

## 使用するアプリ

[Wordを開く](https://word.cloud.microsoft/)

## シチュエーション

ターゲット顧客とマーケティング施策の方向性が整理できました。

次に、関係者とレビューするための具体的なキャンペーン企画案を作成します。

既存のマーケティング資料は使用せず、新しいWord文書から開始します。

## プロンプト

```text
法人向けデジタルサービスのマーケティングキャンペーン企画案を作成してください。

以下の構成にしてください。

1. キャンペーンの背景
2. キャンペーンの目的
3. 想定するターゲット
4. ターゲットが抱えると想定される課題
5. 主要なメッセージ
6. 使用するマーケティングチャネル
7. 作成するコンテンツ
8. Call to Action
9. 効果測定に使用するKPI
10. 実施前に確認する必要がある事項

マーケティングチームがレビューするためのたたき台として、簡潔で具体的な内容にしてください。

確認できていない顧客ニーズや市場情報は断定せず、「要検証」としてください。
```

## 想定する結果

Wordに、例えば以下を含むキャンペーン企画案が作成されます。

- キャンペーン目的
- ターゲット
- 顧客課題
- Value Proposition
- メッセージ
- チャネル
- コンテンツ
- CTA
- KPI
- 要検証事項

## 追加プロンプト：経営層向けに短くする

```text
この企画案の冒頭に、マネージャーが1分程度で読めるエグゼクティブサマリーを追加してください。
```

## 追加プロンプト：実行計画を追加する

```text
このキャンペーンを8週間で実施すると仮定して、準備、実施、効果測定の大まかなスケジュールを追加してください。
```

# 演習1のまとめ

このデモでは、マーケティング担当者が市場を理解してから施策を具体化するまでを体験しました。

| 段階 | マーケティング業務 | 使用するツール |
|---|---|---|
| **Research** | 市場や顧客ニーズを調査する | [リサーチツール](https://copilot.cloud.microsoft/agents/researcher) |
| **Analyze** | マーケティングデータから傾向を見つける | [アナリスト](https://copilot.cloud.microsoft/agents/analyst) |
| **Strategize** | ターゲット、メッセージ、チャネルを整理する | [Microsoft 365 Copilot Chat](https://copilot.cloud.microsoft/home) |
| **Create** | キャンペーン企画を作成する | [Word](https://word.cloud.microsoft/) |

> Copilotにマーケティング戦略そのものを決めてもらうのではなく、市場の事実、手元のデータ、仮説を整理し、人間が次のマーケティング判断を行いやすくすることが、この演習のポイントです。

---

# デモ実施上のポイント

この演習では、できるだけ実際の企業データや過去のマーケティング資料に依存しない構成にしています。

- 既存Outlookメール：使用しない
- 既存Teamsチャット：使用しない
- 過去のマーケティング資料：使用しない
- 実際の顧客データ：使用しない
- 実際のキャンペーンデータ：使用しない

演習1-2のみ、分析対象として小さなサンプルExcelファイルを事前に用意します。

そのため、事前準備が必要なのは基本的に、

1. サンプルExcelファイル
2. リサーチツールのバックアップ用実行結果

の2つです。
