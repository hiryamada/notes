
# Microsoft Copilot Finance向けデモ：演習1

## デモの概要

財務・経理担当者が、部門別の予算と実績を確認し、差異の大きい項目を特定して、関係者とのレビューに備える場面を想定します。

Microsoft Copilotを使用して、財務データの確認、差異分析、要点整理、関係者とのコミュニケーションまでを進めます。

1. 予算と実績を確認する
2. 差異の大きい項目を分析する
3. 財務レビューの要点を整理する
4. 関係者向けの会議メッセージを作成する

> **デモの流れ：Review → Analyze → Explain → Align**

デモの実施時間は合計50分です。

# 演習1-1：予算と実績を確認する

## 使用するアプリ

[Excelを開く](https://excel.cloud.microsoft/)

## シチュエーション

月次の財務レビューに向けて、複数部門の予算と実績を確認します。

実際の企業データは使用せず、デモ用のサンプルExcelファイルを使用します。

## サンプルデータ

サンプルExcelファイルには、次の列を用意します。

- Month
- Department
- Expense Category
- Budget
- Actual
- Variance
- Variance Percentage
- Comment

`Variance` と `Variance Percentage` は空欄でもかまいません。Copilotを使用して追加できます。

## プロンプト

```text
この予算実績データを分析するため、次の作業を行ってください。

1. 実績から予算を引いた「差異」の列を追加してください
2. 予算に対する差異率の列を追加してください
3. 予算超過が大きい項目を特定してください
4. 予算を下回っている項目を特定してください
5. 部門別と費目別の主な傾向を整理してください
6. 財務レビューで優先して確認すべき項目を示してください

差異の原因をデータだけで判断できない場合は、原因を断定せず、追加確認が必要であることを示してください。
```

## 想定する結果

Excel上で、次のような分析が行われます。

- 差異の計算
- 差異率の計算
- 予算超過項目の特定
- 予算未達項目の特定
- 部門別の傾向
- 費目別の傾向
- 確認すべき項目の抽出

> 差異が大きいことと、問題があることは同じではありません。Copilotで数値を整理した後、背景や業務上の理由を人が確認します。

## 追加プロンプト：グラフを作成する

```text
部門ごとの予算と実績を比較できるグラフを作成してください。

予算と実績の違いが分かりやすいグラフを選択してください。
```

## 追加プロンプト：優先項目を絞る

```text
差異率と金額の両方を考慮して、財務レビューで優先して確認すべき項目を5つ選んでください。
```

# 演習1-2：差異の原因候補を分析する

## 使用するツール

[アナリストを開く](https://copilot.cloud.microsoft/agents/analyst)

## シチュエーション

Excelで予算と実績の差異を確認したところ、複数の部門や費目で大きな差異が見つかりました。

次に、財務レビューで確認すべき論点を整理します。

この演習では、演習1-1で使用したサンプルExcelファイルをアナリストに追加します。

## プロンプト

```text
この予算実績データを分析してください。

特に以下を確認してください。

1. 金額ベースで差異が大きい項目
2. 差異率が大きい項目
3. 部門別の特徴
4. 費目別の特徴
5. 複数の部門に共通する傾向
6. 一時的な差異か、継続的な傾向かを確認するために必要な追加情報
7. 財務レビューで関係者に確認すべき質問

分析結果は、次の3つを区別して整理してください。

- データから確認できる事実
- 考えられる原因の仮説
- 追加で確認すべき情報

データだけで原因を確認できない場合は、原因を断定しないでください。
```

## 想定する結果

アナリストによって、次のような情報が整理されます。

- 重要な予算差異
- 部門別・費目別のパターン
- 異常値の可能性がある項目
- データから確認できる事実
- 原因についての仮説
- 追加で必要な情報
- 関係者への確認質問

この演習では、**事実と仮説を混在させないこと**を重視します。

## 追加プロンプト

```text
この分析結果から、経営上の影響が大きい可能性がある項目を3つ選んでください。

それぞれについて、以下を整理してください。

- 確認できる事実
- 想定される影響
- 原因を確認するための質問
- 推奨する次のアクション
```

# 演習1-3：財務レビューの要点を整理する

## 使用するアプリ

[Microsoft 365 Copilot Chatを開く](https://copilot.cloud.microsoft/home)

## シチュエーション

予算と実績の分析ができました。

次に、マネージャーや部門責任者との月次レビューで使用する要点を整理します。

既存のメールや会議データは使用せず、新しいチャットで一般的な財務レビューの構成を作成します。

## プロンプト

```text
月次の予算実績レビューで使用する要点を整理してください。

予算と実績の分析によって、複数の部門や費目で重要な差異が見つかったことを想定してください。

以下の構成にしてください。

1. 全体の状況
2. 優先して確認すべき差異
3. データから確認できる事実
4. 原因を確認する必要がある項目
5. 関係者に確認すべき質問
6. 推奨する次のアクション
7. 次回レビューまでに確認する事項

数値だけを並べるのではなく、マネージャーや部門責任者が短時間で論点を理解できる内容にしてください。

原因が確認できていない差異については、断定的な表現を避けてください。
```

## 想定する結果

財務レビューで使用できる要点が整理されます。

例えば以下です。

- Overall status
- Material variances
- Confirmed facts
- Open questions
- Potential impact
- Recommended actions
- Follow-up items

## 追加プロンプト：経営層向けにする

```text
経営層が1分程度で確認できるように、内容を5つ以内の重要ポイントに絞ってください。
```

## 追加プロンプト：質問リストを作る

```text
部門責任者との財務レビューで使用する質問を、優先順位の高い順に7つ作成してください。
```

# 演習1-4：レビュー会議の案内を作成する

## 使用するアプリ

[Teamsを開く](https://teams.cloud.microsoft/)

## シチュエーション

差異分析と財務レビューの論点が整理できました。

次に、関係者へ月次財務レビュー会議の目的と事前準備を伝えるTeamsメッセージを作成します。

既存のTeamsチャットや既存の会議は使用せず、新規メッセージの下書きを作成します。

## プロンプト

```text
部門責任者に送る、月次予算実績レビュー会議の案内メッセージを作成してください。

メッセージには、以下を含めてください。

1. 会議の目的
2. 予算と実績の差異を確認すること
3. 特に確認したい主な論点
4. 参加者に事前に確認してほしいこと
5. 会議で決めたいこと
6. 必要に応じて追加情報を準備してほしいこと

差異があることを問題だと決めつけず、背景と今後の対応を一緒に確認する、協力的で簡潔な文章にしてください。
```

## 想定する結果

Teamsで使用できるメッセージの下書きが作成されます。

メッセージには次の内容が含まれます。

- 会議の目的
- 主な確認項目
- 事前準備
- 会議で決定したい内容
- 協力を依頼する文章

## 追加プロンプト：短くする

```text
Teamsチャットで読みやすいように、重要な内容を維持したまま短くしてください。
```

## 追加プロンプト：アジェンダを追加する

```text
30分の会議として、時間配分付きの簡潔なアジェンダを追加してください。
```

# 演習1のまとめ

このデモでは、財務担当者が予算と実績を確認し、差異の論点を整理して、関係者とのレビューに備えるまでを体験しました。

| 段階 | 財務業務 | 使用するツール |
|---|---|---|
| **Review** | 予算と実績を確認する | [Excel](https://excel.cloud.microsoft/) |
| **Analyze** | 重要な差異と確認事項を分析する | [アナリスト](https://copilot.cloud.microsoft/agents/analyst) |
| **Explain** | 財務レビューの要点を整理する | [Microsoft 365 Copilot Chat](https://copilot.cloud.microsoft/home) |
| **Align** | 関係者へレビュー会議の目的を伝える | [Teams](https://teams.cloud.microsoft/) |

> Copilotに財務判断を任せるのではなく、数字を正確に確認し、事実と仮説を区別し、関係者が次の判断を行える形に整理することが、この演習のポイントです。

# デモ実施上のポイント

この演習では、実際の財務データや既存の社内コミュニケーションを使用しません。

- 実際の予算実績データ：使用しない
- 既存の財務資料：使用しない
- 既存Outlookメール：使用しない
- 既存Teamsチャット：使用しない
- 既存の会議データ：使用しない
- 契約書や契約分析：使用しない

演習1-1と演習1-2では、同じデモ用サンプルExcelファイルを使用します。

そのため、事前に必要な主な準備は次の2つです。

1. 予算実績のサンプルExcelファイル
2. アナリストのバックアップ用実行結果

## サンプルデータを準備する際の注意

サンプルデータには、デモで説明しやすいように、次のような特徴を意図的に含めます。

- 金額は大きいが差異率は小さい項目
- 金額は小さいが差異率は大きい項目
- 複数部門に共通する費目の増加
- 予算を下回っている項目
- 一時的な差異に見える項目
- 原因をデータだけでは判断できない項目

これにより、「最大値だけを見る」のではなく、金額、差異率、傾向、業務への影響を組み合わせて確認するデモができます。
