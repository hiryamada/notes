# PL-7008 まとめ

このコースでは以下について解説しました

- 環境構築（Power Platformの環境、Dataverse、ソリューションの作成）
- Dataverseテーブルの作成
- Microsoft Copilot Studioの新旧インターフェースの説明
  - 新: New Experience
  - 旧: Classic Experience
  - Classic ExperienceからNew Experienceへの切り替え方法
- Microsoft Copilot Studioでのエージェントの作成
  - ツール（Dataverseテーブルの読み書き）
  - ナレッジ（Webサイトの接続）
- エージェントの利用
  - 公開
  - Microsoft Teamsでのエージェントの利用
- エージェントの高度な機能
  - Skills（ツールの利用方法などの指示）
  - メモリ（ユーザーの指示の記録）
  - Connected Agents（子エージェントを接続する）

ラボ環境は半年後まで利用できますので、ぜひ練習・復習にご活用ください。
