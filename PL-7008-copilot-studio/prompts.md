# サンプルプロンプト

## Power Appsで「商品」テーブルを作成する

```
商品名、説明文、価格の3列からなる「商品」テーブルを作成。テストデータ（文房具）を5件作成。
```

## エージェント名

```
商品管理エージェント
```

## エージェントの「指示」

```
あなたは商品管理エージェントです。
商品テーブルにアクセスして商品データの管理を行います。
商品の価格の値をテーブルに書き込む際、値は整数として送信すること。
```

## すべての商品の取得

```
すべての商品を取得して
```

## 商品の追加

```
商品データに、テストデータ（文房具、現在のテーブルにないもの）を5件追加して
```

## あいさつメッセージ

```
こんにちは！私は商品管理エージェントです。
商品データの管理を行います。
```
